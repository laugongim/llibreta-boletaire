# Llibreta Boletaire

App per aprendre a reconèixer els bolets del Berguedà: fitxes, fotos, reactius de camp, mapa per zones i clau d'identificació guiada. S'instal·la al mòbil ("Afegeix a la pantalla d'inici") i funciona sense cobertura.

**Avís:** és un prototip pendent de revisió per una societat micològica. L'app serveix per aprendre, no per decidir què et menges.

Fotos: Wikimedia Commons (autor i llicència a cada fitxa). Límits municipals del mapa: © col·laboradors d'OpenStreetMap (ODbL).

Aquests fitxers es generen amb `build_pwa.py`; no s'editen a mà.
